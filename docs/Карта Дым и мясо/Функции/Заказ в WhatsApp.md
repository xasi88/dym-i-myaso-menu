## Правила

- Кнопка открывает WhatsApp шефа с готовым текстом: приветствие, список, итог, способ получения, адрес, имя, время, пожелания.
- При доставке без адреса заказ не уходит. Появляется подсказка «Укажите адрес доставки».
- Номер берётся из `SHOP.phone` в `data/menu.js`.
